# 玻璃底片射影配准审计（Glass-plate Homography Audit）

复拍玻璃底片时，透视与少量基准点误标会产生两套坐标。逐点拟合可能让错误对应主导校正。
本应用是一个**仅在浏览器运行**的 TypeScript / React 审计页：粘贴或编辑对应点后启动审计，
用 **BigInt 精确有理数运算**从非退化四点射影标架生成射影变换，精确判定全部对应关系，
并在 SVG 中给出可核对的重合点、离群点与残差连线证据。

- 无业务后端、无在线服务、判定路径不发起任何网络请求；构建产物为纯静态文件。
- 同一输入永远得到同一结果（确定性、可复算）。

## 输入规则

每行一个点，字段为 `标识, X₁, Y₁, X₂, Y₂`（逗号、制表符、分号或空白分隔；`#` 起始为注释）：

- 每批 **8–40** 个标识唯一的对应点；
- 两侧坐标均为绝对值 **≤ 1,000,000 的整数**；
- 同侧坐标不得重复；
- 离群上限为 **0–4** 的整数。

任一条不满足都会给出具体原因（含行号），且不产生图形。

## 精确判据

### 1. 四点射影标架生成变换

四个“无三点共线”的点构成一个**射影标架**，唯一确定一个射影变换（平面单应）。
设前三点齐次坐标组成列矩阵 `M=[p1 p2 p3]`，第四点的重心坐标由
`M⁻¹p4 = (q₁,q₂,q₃)/d` 给出，其中 `(q₁,q₂,q₃)ᵀ = adj(M)·p4`（`adj` 为整数伴随矩阵）。
标架的整数提升矩阵为 `L = M·diag(q₁,q₂,q₃)`。源标架 A → 目标标架 B 的变换为

```
H = L_B · L_A⁻¹ = L_B · adj(L_A) / det(L_A)
```

审计热路径直接使用整数代表元 `G = L_B · adj(L_A)`（与 H 相差非零标量 `1/det(L_A)`，
射影等价），因此枚举与判定全程为 BigInt 整数运算；仅在需要展示分数坐标时使用有理数。

### 2. 精确对应判定

对 `G·(x,y,1)=(X,Y,W)`，点 `(x,y)` 与 `(u,v)` **精确重合**当且仅当

```
W ≠ 0   且   X = u·W   且   Y = v·W
```

`W = 0` 表示像在无穷远（分母为零），判为不重合。**不使用任何浮点或 ε 容差**——一单位的
误标即为离群。

### 3. 优化目标与规范解

枚举两侧均为标架的所有四点组合，精确统计各自的保留/离群点：

1. **先最小化离群数**；
2. 并列时按**规范化九整数矩阵系数的字典序**选取规范解。规范化为：九整数通分后整体约去
   最大公因数，再令按行优先顺序的首个非零系数为正（即射影等价类在 P⁸(Q) 中的唯一整数代表）；
3. 统计达到最少离群数的**不同最优变换个数**（以规范形去重）。

任一全局最优保留集必含四点标架（≥4 个真实对应在射影下无三点共线），因此该枚举对“最小离群”
是**精确**的，而非 RANSAC 式抽样近似。

### 4. 失败处理

- 保留点中找不到四点标架（或其第二侧对应不构成标架）；
- 出现分母为零导致无法确定有限像；
- 最少离群数超过给定上限；

页面会说明失败原因，**保留原输入并清除旧图**。

## 页面证据

成功时展示：

- 规范射影变换的九整数矩阵；
- 保留与剔除的点标识、离群数、并列最优变换数、枚举标架数；
- SVG 叠加图：绿色重合点（H(A)=B 精确相等）、蓝色 × 为 H(A) 投影位置、红色 □ 为 B 侧实测点、
  橙色虚线为离群残差 H(A)→B；
- 逐点核对表：每点的 A、B 坐标与 **H(A) 的精确（分数）坐标**及判定。

```bash
npm ci

npm run build        # 类型检查 + 产出 dist/
```

## Docker 发布与一次性验收

多阶段 `Dockerfile`：`web` 阶段为 nginx 静态镜像（含 `/healthz` 健康检查），
`verify` 阶段内置 Node、vitest、Playwright 与 Chromium，离线运行验收。

`docker-compose.yml` 提供：

- `app`：发布审计页，宿主机端口可用 `HOST_PORT` 配置（默认 8080），带健康检查；
- `verify`：**一次性**服务，启动后运行精确判据单元测试与针对**已发布页面**的 Playwright
  真实操作，随后自行退出，并以退出码报告结果（0 通过 / 非零失败）。它只接入
  `internal` 网络（`internal: true`，无外网网关），构建后可完全离线运行。

```bash
# 发布（自定义宿主机端口）
HOST_PORT=9090 docker compose up -d app
curl -fsS http://localhost:9090/healthz        # -> ok

# 一次性离线验收（退出码即结论）
docker compose build verify
docker compose run --rm verify
echo "verify exit code: $?"
```

`verify` 内执行 `npm run test:unit`（26 项精确判据）与 `npx playwright test`
（5 项真实页面操作：示例批次精确矩阵与划分、SVG 证据、超上限失败保留输入清图、
无标架失败、输入编辑后重新判定，并断言页面不访问非本站来源）。
